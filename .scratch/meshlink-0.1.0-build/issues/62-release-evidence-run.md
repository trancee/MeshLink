# Pass the 8-phone release evidence run

Status: ready-for-human
Type: HITL
Blocked by: 43, 57, 61

## Behavior

The 0.1.0 build passes every pairwise and mesh scenario of ADR 0017's release amendment on the 8 release phones, and the run becomes a T9 evidence record in `docs/evidence/`. Every message arrives exactly once, intact and within its lifetime, with matching receipts and no crash or ANR. Latency, throughput and connect time become the P4 baseline for later releases.

## Acceptance criteria

- [ ] An agent runs `tools/lab/` from a dedicated worktree at the release candidate commit on `main`, and records that commit. The owner is on call for physical faults.
- [ ] **Pairwise:** each pair runs twice, roles swapped. The plan covers Android↔Android (`p10lite`–`pixel6`, `xcover4`–`nothing2`), Android↔iOS (`p10lite`–`ip12mini`, `pixel6`–`se2016`, `xcover4`–`ipx`, `nothing2`–`ip15`) and iOS↔iOS (`se2016`–`ip12mini`, `ipx`–`ip15`), so every pairing includes the oldest and the newest OS on each side.
- [ ] Each pair runs discovery, handshake, direct unicast with delivery and read receipts, and a 128 KiB message over GATT, plus over L2CAP CoC where both phones support it. Direct unicast runs under `Unsecured`, `Classical` and `PostQuantum`; the other scenarios run under `Classical`.
- [ ] **Mesh:** the 8 phones form a mixed-platform line of at least 3 hops, forced by the lab-only topology filter from ticket 43. Routed unicast, signed broadcast, store-and-forward (a relay goes offline and returns) and link churn each pass under `Classical`.
- [ ] **Pass:** every message is delivered within its lifetime, exactly once and intact, receipts match, and no phone crashes or shows an ANR. A miss blocks the release unless the record root-causes it to an external fault. A product bug becomes a new ticket with a `VirtualAir` regression case, and the run repeats after its fix.
- [ ] **Baseline (P4):** the record holds latency, throughput and connect time per scenario and pair, with the environment metadata of T11, marked as the 0.1.0 baseline.
- [ ] `python3 tools/lab/lab.py evidence --run <dir>` writes the record with every T9 field. Bluetooth addresses are pseudonymized, and only aliases appear. Density stays simulator evidence and background behavior is marked unverified.
- [ ] The `CHANGELOG.md` "Unreleased" section links the record. `python3 tools/check_private.py` and the docs checks pass.
